# Brand Color Palette

This document defines the core visual tokens and colors used across the site.

## Base Palette
* **Gold**: `#F1C84B` (Primary CTA)
* **Sage (Light)**: `#A9D6BB` (Secondary, Success)
* **Sage (Dark)**: `#7DA88D` (Secondary, Success for Dark Mode)

## CSS Variables / Tokens

| Token Role | Light Mode (Default) | Dark Mode Equivalent | Visual Purpose |
| :--- | :--- | :--- | :--- |
| `--bg-app` | `#FFFFFF` | `#141715` | Main app background canvas |
| `--bg-card` | `#F6EAB6` | `#1E2420` | Cards, panels, and container surfaces |
| `--bg-subtle` | `#FDFBF7` | `#28302A` | Secondary fill, active states, soft highlights |
| `--text-primary` | `#4A4A4A` | `#E6ECE8` | Body text, headings, and primary icons |
| `--text-on-accent`| `#4A4A4A` | `#141715` | High-contrast text rendered over gold/sage buttons |
| `--brand-gold` | `#F1C84B` | `#F1C84B` | Primary call-to-action (CTA) buttons |
| `--brand-sage` | `#A9D6BB` | `#7DA88D` | Secondary buttons, tags, success indicators |
| `--border-color` | `#E2DED4` | `#2C352F` | Subtle dividing lines and card outlines |
